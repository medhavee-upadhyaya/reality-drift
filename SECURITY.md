# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability, exposed credential, or report containing sensitive scraped data. Use GitHub's private vulnerability reporting for this repository when available, or contact the maintainer through the email listed on their GitHub profile.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Please allow a reasonable remediation window before public disclosure.

## Scope notes

- Never commit `.env` files or API keys.
- Treat collected web content as untrusted input.
- Avoid submitting personal employee data in fixtures or issue reports.
- Reality Drift findings are research signals, not legal conclusions.
